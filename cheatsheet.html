Vibe Workspace

Cẩm nang phím tắt & cách dùng cho môi trường tmux · Neovim · Claude Code. Một nguồn tra cứu duy nhất.

Không tìm thấy phím nào khớp — thử từ khoá khác.

Một source, nhiều git worktree chạy song song. Mỗi worktree là một workspace cách ly: tmux session riêng, Neovim riêng, và nhiều Claude Code vibe code cùng lúc.

Attach vào một workspace là full màn hình; các workspace khác vẫn chạy nền. Đóng terminal, Claude vẫn chạy — mở lại là nguyên trạng.

1
tmux — tầng cách ly workspace
Mỗi session = một worktree. Chuyển bằng sesh, persistence qua reboot.
2
Neovim — editor mỗi worktree
Mở đúng thư mục worktree, LSP đúng root, xem code AI vibe.
3
Claude Code — nhiều phiên
Trong nvim (claude-multi) hoặc pane tmux. Gửi selection, xem diff (claudecode).

Luồng làm việc điển hình

  1. Mở tmux. Terminal thường tự vào tmux (trừ Warp). Hoặc gõ tmux.
  2. Tạo workspace. wt-new feat-login → tạo worktree + session + nvim tự mở.
  3. Vibe code. Trong nvim: Space c n mở Claude Code; thêm phiên nữa cũng Space c n.
  4. Gửi ngữ cảnh. Bôi đen code → Space a s gửi cho Claude; Space a a nhận diff.
  5. Tập trung. Space z hoặc prefix z zoom full.
  6. Nhảy workspace. prefix o → popup xem tất cả, chọn cái khác (cái cũ vẫn chạy).
  7. Dọn. Xong feature → wt-clean xoá worktree đã merge.
Leader = Space, tmux prefix = Ctrl+a. Trong nvim, bấm Space rồi khựng lại → which-key hiện popup nhắc mọi phím. Trong tmux, quên thì mở tab tương ứng ở đây.

Prefix là Ctrl+a. Bấm prefix rồi bấm phím lệnh.

Ba script wt-* quản vòng đời worktree. sesh nhảy giữa workspace, zoxide nhảy tới thư mục bất kỳ.

Scripts worktree ~/thai/system/bin

wt-new <branch>
Tạo worktree + branch + tmux session + nvim tự mở. Đường dẫn: <repo>.worktrees/<branch>
wt-status
Bảng tổng quan mọi worktree: branch · số file đổi · số Claude Code đang chạy
wt-clean
Dọn worktree đã merge vào main + kill session. Worktree còn thay đổi chưa lưu sẽ được giữ lại + cảnh báo
