# Codex

Portable Codex configuration exported from `~/.codex`.

Tracked:

- `config.toml` without machine-specific project trust entries
- reusable prompts
- user rules

Runtime state is intentionally excluded, including authentication, accounts,
sessions, history, logs, databases, caches, generated images, plugins and
system-managed skills.

Restore the tracked files into `~/.codex` without replacing that whole runtime
directory.
