Không tìm thấy phím nào khớp — thử từ khoá khác.

Một source, nhiều git worktree chạy song song. Mỗi worktree là một workspace cách ly: tmux session riêng, Neovim riêng, và nhiều Claude Code vibe code cùng lúc.

Attach vào một workspace là full màn hình; các workspace khác vẫn chạy nền. Đóng terminal, Claude vẫn chạy — mở lại là nguyên trạng.

1
tmux — tầng cách ly workspace
Mỗi session = một worktree. Chuyển bằng sesh, sống qua reboot.
2
Neovim — editor mỗi worktree
Mở đúng thư mục worktree, LSP đúng root, xem code AI vibe.
3
Claude Code — nhiều phiên
Trong nvim (claude-multi) hoặc pane tmux. Gửi selection, xem diff (claudecode).

Luồng làm việc điển hình

  1. Mở tmux. Terminal thường tự vào tmux (trừ Warp). Hoặc gõ tmux.
  2. Tạo workspace. wt-new feat-login → worktree + session + nvim tự mở.
  3. Vibe code. Trong nvim: Space c n mở Claude Code; thêm phiên nữa cũng Space c n.
  4. Gửi ngữ cảnh. Bôi đen code → Space a s; nhận diff Space a a.
  5. Tập trung. Space z hoặc prefix z zoom full.
  6. Nhảy workspace. prefix o — cái cũ vẫn chạy nền.
  7. Dọn. wt-clean xoá worktree đã merge.
