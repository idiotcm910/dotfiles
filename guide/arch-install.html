Trước khi rút USB

Chốt đúng phạm vi cài

Guide này tối ưu cho một máy code tối giản. Nếu còn Windows, nhiều ổ dữ liệu hoặc cần dual boot, dừng tại đây và lập sơ đồ phân vùng riêng.

Nhận diện ổ trước khi reboot
lsblk -o NAME,SIZE,MODEL,TYPE,FSTYPE,MOUNTPOINTS

An toàn dữ liệu

Backup và mở thử dữ liệu

Repo dotfiles đã ở GitHub, nhưng repo không giữ credential, session AI, source chưa push, database local hoặc profile trình duyệt.

Tìm repo còn thay đổi chưa commit
find ~/thai -name .git -type d -prune -print | while read -r gitdir; do
  repo="${gitdir%/.git}"
  git -C "$repo" status --short
done

04

Firmware

Boot USB đúng chế độ UEFI

ISO Arch không hỗ trợ Secure Boot mặc định. Tắt Secure Boot tạm thời; có thể cấu hình lại bằng khóa riêng sau khi hệ thống đã ổn định. Với ThinkPad T490 của tui: cắm USB, bật máy rồi bấm liên tục F12 khi logo ThinkPad hiện ra; nếu hàng phím F đang là media key thì bấm Fn + F12.

Boot menu không hiện: reboot, bấm F1 vào BIOS → Startup → bật F12 Boot Device List. Trong boot menu, chọn USB có nhãn UEFI (thường là USB HDD hoặc tên hãng USB), không chọn mục Legacy.
Lenovo ThinkPad Boot Menu ↗
Kiểm tra UEFI trong live ISO
test -d /sys/firmware/efi/efivars && echo "UEFI: OK"
05

Live environment

Kết nối mạng và kiểm tra lại ổ

Ethernet thường tự nhận. Với Wi‑Fi, dùng iwctl; thay wlan0 và tên mạng bằng giá trị thật từ máy.

Kết nối Wi‑Fi
iwctl
device list
station wlan0 scan
station wlan0 get-networks
station wlan0 connect TEN_WIFI
exit
ping -c 3 archlinux.org
Đồng bộ giờ và xem ổ
timedatectl
lsblk -o NAME,SIZE,MODEL,TYPE,FSTYPE,MOUNTPOINTS

07

First boot

Vào Arch base và xác nhận nền tảng

Rút USB sau khi máy bắt đầu reboot. Đăng nhập bằng user thường, kiểm tra mạng rồi cập nhật full system trước khi dựng desktop.

Kiểm tra và cập nhật hệ thống
systemctl status NetworkManager --no-pager
ping -c 3 archlinux.org
sudo pacman -Syu
08

Dotfiles

Kéo repo và dựng Qtile workspace

Clone bằng HTTPS trước vì SSH key chưa được khôi phục. Luôn chạy dry-run và đọc toàn bộ plan trước lần chạy thật.

Clone và preview
sudo pacman -S --needed git base-devel
mkdir -p ~/thai
git clone https://github.com/idiotcm910/dotfiles.git ~/thai/system
cd ~/thai/system
bash restore.sh --dry-run
Chạy restore sau khi đã review
cd ~/thai/system
bash restore.sh
09

Xác nhận hoàn tất

Vào Qtile và mở lại workflow code

Reboot lần cuối, đăng nhập TTY rồi chạy startx. Qtile autostart sẽ dựng wallpaper, Polybar và IBus.

Khởi động desktop và kiểm tra tool
startx
# Sau khi vào terminal trong Qtile:
nvim --version
tmux -V
sesh --version
codex --version
claude --version

Đích đến: một Arch base nhỏ, desktop Qtile có thể dựng lại từ Git, và workflow code không phụ thuộc ký ức của lần cài trước.
