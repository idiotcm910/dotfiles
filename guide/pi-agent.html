Tài khoản · /acc pi-accounts

Vault nhiều account Antigravity + xAI (Grok). Kết quả lệnh hiện dạng overlay pager nổi (cuộn được, không vào context AI, đóng bằng Enter / Esc / q).

/acc
Help ngắn + active mỗi provider
/acc ls
Panel TUI (không vào context AI) · card nhiều dòng · * active
/acc clear
Đóng panel /acc
/acc usage
Refresh usage tất cả rồi in card (plan + từng quota một dòng)
/acc usage <alias>
Refresh đúng một alias
/acc add <provider> <alias>
OAuth riêng (không gọi /login) · lưu vault · active nếu provider chưa có active
/acc switch <alias>
Chờ idle → sync active cũ → ghi slot → đánh dấu active
/acc rename <old> <new>
Đổi alias (trùng = lỗi)
/acc rm <alias>
Xoá account không active
/acc rm <alias> --force
Xoá cả khi active + xoá key provider trong auth.json
/acc adopt <alias> [provider]
Nhận credential đang nằm trong auth.json vào vault (alias mới bắt buộc provider)

Provider & alias

antigravity · agy
→ provider antigravity
xai · grok
→ provider xai
[A-Za-z0-9][A-Za-z0-9_-]{0,31}
Alias 1–32 ký tự · không space · không bắt đầu bằng -

Ví dụ hằng ngày:

/acc add agy work
Login Google → vault work
/acc add agy home
Account thứ hai · thường stored, not active
/acc add grok personal
Login xAI device-code
/acc switch home
Request Antigravity kế tiếp dùng home
/acc ls
Xem * active + usage cache
/acc usage
Cập nhật quota (xAI có thể quota n/a)
/acc adopt extra antigravity
Sau /login antigravity — gắn slot vào vault

File & bảo mật secrets

~/.pi/agent/accounts.json
Vault multi-account · mode 0600 · không commit · không restore
~/.pi/agent/auth.json
Slot live của Pi (1 credential / provider) · extension chỉ đụng key antigravity + xai
.pi/agent/extensions/pi-accounts/
Source trong repo · restore profile ai copy vào ~/.pi/agent/extensions/
Không in token. Lệnh không bao giờ hiện access/refresh/JWT. Active rm cần --force. Alias sai gõ gần đúng sẽ gợi ý: did you mean: ….
Nhớ: /run <agent> <task> · design dùng /design · account dùng /acc ls · /acc switch <alias> · thêm account /acc add agy|grok <alias> · nền thêm --bg.
