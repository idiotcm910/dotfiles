Arch mới

Clone và restore Wayland

Restore
git clone <URL-REPO> ~/thai/system && cd ~/thai/system && ./restore.sh --dry-run --profile wayland --only desktop && ./restore.sh --profile wayland

Wayland session

Khởi động Hyprland với DBus

Từ tty, dùng DBus session để IBus, Mako và portal hoạt động; không dùng startx.

Chạy phiên đầu tiên
dbus-run-session Hyprland
