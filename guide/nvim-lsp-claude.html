claudecode — tích hợp IDE Space a …

Spaceas
Gửi selection (bôi đen) cho Claude — chế độ visual
Spaceaa / Spacead
Nhận / từ chối diff Claude đề xuất
Spaceab
Thêm buffer hiện tại làm ngữ cảnh
Spaceac / Spaceaf
Toggle / focus cửa sổ Claude IDE
Spaceam
Chọn model
Khi Claude đề xuất sửa, claudecode mở diff 2 cột ngay trong nvim — bạn chỉnh lại rồi Spaceaa để nhận. Hai nhóm phím tách bạch: Spacec = claude-multi, Spacea = claudecode.
