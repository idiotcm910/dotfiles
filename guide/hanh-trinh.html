Không tìm thấy phím nào khớp — thử từ khoá khác.

Đọc từ trên xuống là đi hết một vòng: mở máy → tạo workspace → làm việc → nhìn tất cả cùng lúc → tạm rời → dọn. Các trang khác là từ điển tra phím; trang này trả lời “giờ tôi bấm gì”.

1 · Mở máy

—
Mở terminal là tự vào tmux session main — khối auto-tmux trong .bashrc lo việc đó. Không cần gõ gì
tmux attach
Lỡ thoát hẳn ra ngoài thì vào lại. Mọi thứ vẫn y nguyên chỗ cũ

2 · Mở workspace mới

wt-new <branch>
Một lệnh làm bốn việc: tạo worktree tại <repo>.worktrees/<branch>, tạo branch nếu chưa có, tạo tmux session, rồi mở nvim sẵn trong đó
wt-status
Bảng tổng quan mọi worktree: branch · số file đã đổi · số Claude Code đang chạy trong đó

Tên session lấy từ tên branch, thay . / : thành _ — nên feat/api thành session feat_api.

3 · Làm việc

Spacecn
Mở một Claude Code mới trong nvim. Bấm nữa để mở thêm cái nữa
Spaceas
Bôi đen code trước, rồi bấm để gửi đoạn đang chọn cho Claude
Spaceaa
Nhận diff Claude đề xuất
Spacez
Zoom cửa sổ nvim đang đứng cho rộng

Đầy đủ phím nvim và Claude → Nvim · LSP & Claude.

4 · Chạy nhiều việc song song

prefixrồic
Window mới — như mở thêm một tab, chiếm trọn màn hình
prefixrồi|
Chia dọc — hai pane cạnh nhau, giữ nguyên thư mục
prefixrồi-
Chia ngang — hai pane trên dưới, giữ nguyên thư mục
prefixrồie
Bật/tắt sync-panes — gõ một lệnh chạy trên mọi pane cùng lúc

Window cho việc riêng biệt, pane cho hai thứ cần nhìn cùng lúc. Nhiều Claude thì cứ mỗi cái một window, khi nào cần so sánh thì gộp lại — xem bước 5.

5 · Nhìn tất cả cùng lúc lưới pane

Ba window, mỗi cái một Claude. Muốn nhìn cả ba thì gộp thành lưới trong một window, xong lại tách trả về như cũ.

prefixrồig
Gộp / tách. Lần đầu hiện popup chọn layout (tiled = lưới đều, hợp nhất), rồi hút mọi window thành pane. Bấm lại: mỗi pane về đúng window cũ, đúng tên, đúng thứ tự. Esc ở popup = huỷ, không đổi gì
Ctrl+hjkl
Nhảy pane theo hướng — xuyên cả nvim lẫn tmux, không cần prefix
prefixrồiq
Nhảy pane theo số — hiện số to trên mỗi pane, bấm số đó để tới thẳng
prefixrồiz
Phóng to pane đang đứng chiếm cả window. Bấm lại về lưới
prefixrồiSpace
Đổi kiểu chia — xoay qua các layout dựng sẵn, không cần tách ra gộp lại
prefixrồiCtrl+←→↑↓
Chỉnh kích thước pane 1 ô. Giữ Ctrl+a một lần rồi bấm mũi tên liên tục được
prefixrồiAlt+←→↑↓
Chỉnh kích thước 5 ô một nhịp — nhanh hơn khi cần kéo nhiều
prefixrồi←→↑↓
Mũi tên trơn là nhảy pane. Kèm Ctrl/Alt mới là chỉnh kích thước — chỗ này rất dễ nhầm
prefixrồi|
Mở thêm pane khi đang ở lưới. Pane này ở lại lúc bạn tách lưới ra, không bị mang đi đâu cả
Đang ở trong lưới thì prefixrồi123 không còn tác dụng — cả session gộp lại chỉ còn một window, không còn gì để nhảy. Dùng prefixrồiq hoặc Ctrl+hjkl thay thế.

6 · Nhảy qua workspace khác

prefixrồio
Switcher — popup liệt kê mọi workspace, gõ để lọc, Enter để nhảy
prefixrồis
Cây session tích hợp của tmux, không cần fzf

Workspace cũ vẫn chạy nền — Claude trong đó không hề dừng lại khi bạn nhảy đi.

7 · Tạm rời, mai làm tiếp

prefixrồid
Detach — rời tmux, mọi thứ chạy tiếp dưới nền. Đóng luôn cửa sổ terminal cũng không sao
tmux attach
Vào lại đúng chỗ đã rời
prefixrồiCtrl+s
Lưu trạng thái ngay, không đợi tới nhịp tự lưu

Continuum tự lưu mỗi 15 phút và tự khôi phục khi mở tmux — workspace sống qua cả reboot.

8 · Xong hẳn

git add -A && git commit
Lưu việc lại trước đã — mọi bước dọn dẹp phía dưới đều giả định code đã commit
git push -u origin <branch>
Đẩy lên remote rồi mở PR trên GitHub. Code đã nằm trên remote thì dọn gì ở máy cũng an toàn
wt-clean
Sau khi PR đã merge: quét dọn mọi worktree đã merge vào main, kill session, quên đường dẫn zoxide. Worktree còn thay đổi chưa lưu được giữ lại kèm cảnh báo
wt-rm <branch>
Xoá đúng một workspace bạn chỉ định, bất kể đã merge hay chưa. Thêm --force nếu còn thay đổi chưa lưu

Bốn kiểu “đóng” — đừng nhầm

prefixrồid
Không mất gì. Rời màn hình, Claude chạy tiếp dưới nền. Dùng khi tắt máy, mai làm tiếp
prefixrồiShift+x
Đóng một window trong workspace (có hỏi lại). Dùng khi xong một việc nhỏ
prefixrồiShift+q
Đóng cả session (có hỏi lại). Code trên đĩa còn nguyên, worktree vẫn đó — chỉ mất cái màn hình
wt-rm <branch>
Xoá worktree và chạy git branch -D. Đây là cái duy nhất làm mất code nếu branch chưa merge
Lỡ wt-rm nhầm branch chưa merge? Commit vẫn còn: git reflog tìm SHA cuối cùng, rồi git branch <tên> <sha> dựng lại. Chỉ mất phần chưa commit.
