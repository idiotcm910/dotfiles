Không tìm thấy phím nào khớp — thử từ khoá khác.

Ba script wt-* quản vòng đời worktree. sesh nhảy giữa workspace, zoxide nhảy tới thư mục bất kỳ.

Scripts worktree ~/thai/system/bin

wt-rm = xóa đúng một cái bạn chỉ định. wt-clean = quét dọn tất cả cái đã merge. Cần xóa workspace chưa merge → dùng wt-rm.

wt-new <branch>
Tạo worktree + branch + tmux session + nvim tự mở. Đường dẫn: <repo>.worktrees/<branch>
wt-status
Bảng tổng quan mọi worktree: branch · số file đổi · số Claude Code đang chạy
wt-rm <branch>
Xóa MỘT workspace cụ thể (bất kể merged): worktree + branch + session + quên zoxide. Thêm --force nếu còn thay đổi chưa lưu
wt-clean
Dọn HÀNG LOẠT worktree đã merge vào main + kill session + quên zoxide. Worktree còn thay đổi chưa lưu được giữ lại + cảnh báo

sesh — nhảy workspace

prefixrồio
Popup fuzzy: tmux session + thư mục zoxide + config. Gõ để lọc, Enter để nhảy

Lưới pane — nhìn cả session cùng lúc

Session có nhiều window, mỗi window một Claude Code. Gộp lại thành lưới để theo dõi tất cả, zoom cái nào đang làm, rồi tách về như cũ. Không mất pane nào.

prefixrồig
Gộp / tách. Lần đầu: chọn layout trong popup (tiled chia lưới đều — hợp nhất), mọi window thành pane. Bấm lại: mỗi pane về đúng window cũ, đúng tên cũ
prefixrồiz
Phóng to pane đang đứng chiếm cả window. Bấm lại về lưới. Dùng khi cần tập trung một việc
Ctrlh/j/k/l
Nhảy pane theo hướng, xuyên cả nvim. Pane bạn tự mở thêm khi đang ở lưới sẽ ở lại, không bị tách đi

zoxide — nhảy tới thư mục

Học đường dẫn khi bạn cd/z. Càng dùng càng xếp hạng thông minh.

z vibe
Nhảy tới thư mục khớp "vibe" (điểm cao nhất)
z lovinbot api
Nhiều từ khoá → thu hẹp kết quả
zi vid
Chọn tương tác (fzf) nếu nhiều thư mục khớp
zoxide query --list
Xem tất cả thư mục đã học
Một worktree chạy được nhiều Claude Code — trong nvim (Spacecn) hoặc mở pane tmux rồi gõ claude. Xem trang Nvim · LSP & Claude.
